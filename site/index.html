Fonctions Installer Questions

      Le menu Apple, sur Windows.

      Une barre fine reste en haut de l’écran : le menu système à gauche, vos applications, vos fenêtres ouvertes et l’heure. Un clic, et vous éteignez, redémarrez, verrouillez ou lancez un programme.

      Télécharger le MSI Voir le code

      Raccourci : Ctrl + Alt + M. Essayez-le sur cette page.

      Essayez le menu

      Cliquez sur le bouton noir entouré de bleu, ou sur « Applications », en haut à gauche. Cette démo ne touche pas à votre ordinateur : elle affiche ce que l’application ferait.

      En attente d’une action…

      Chaque entrée fait une chose.

      Le menu reprend l’organisation de celui de macOS et appelle les outils déjà présents dans Windows. Rien n’est réinstallé ni remplacé.

      Installez-le en trois étapes.

      Le programme se lance tout seul à chaque ouverture de session. Il tient dans un seul fichier de moins de 2 Mo, et la barre réserve sa place en haut de l’écran : les fenêtres agrandies s’arrêtent juste dessous.

      1. Choisissez votre MSI

        Un fichier par type de PC : 64 bits, ARM ou 32 bits. La page vous indique le bon, sinon voyez ci-dessous.

      2. Lancez l’installation

        Double-cliquez sur le fichier et acceptez la demande d’administrateur. Le bouton apparaît tout de suite en haut à gauche.

      3. Utilisez le menu

        Cliquez sur le bouton, sur l’icône de la zone de notification, ou tapez Ctrl + Alt + M.

      Questions fréquentes

      Les réponses courtes, avant d’installer.

      Windows affiche « Windows a protégé votre ordinateur ». Que faire ?

      Le fichier n’est pas signé avec un certificat payant, donc SmartScreen le signale. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Vous pouvez aussi lire le code source et compiler le MSI vous-même.

      Comment le désinstaller ?

      Ouvrez Paramètres, puis Applications, puis Applications installées. Cherchez « Menu Windows » et choisissez Désinstaller. Le démarrage automatique est supprimé en même temps.

      Le bouton gêne une fenêtre, que faire ?

      Il est petit et fixé dans le coin. Si vous préférez ne pas le voir, quittez-le avec la dernière entrée du menu, puis relancez-le depuis le menu Démarrer quand vous en avez besoin.

      Le programme envoie-t-il des données ?

      Non. Il n’utilise pas Internet : il appelle uniquement des fonctions de Windows quand vous cliquez sur une entrée.

      Peut-on garder la barre des tâches de Windows ?

      Oui. La barre de Menu Windows s’ajoute en haut et ne remplace rien. Vous pouvez laisser celle de Windows en bas, ou la masquer automatiquement dans les paramètres de Windows.

      Quelles versions de Windows sont prises en charge ?

      Windows 10 et Windows 11, en 64 bits (x64), sur ARM (ARM64) et en 32 bits (x86). Il n’existe pas de version pour macOS ni Linux.
